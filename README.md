# slime-rancher-planner
Interactive Slime Rancher ranch planner and completion tracker

## Credits

This project is based on the original Slime Rancher Planner by Bartosz Rodziewicz and the Slime Rancher Planner REBORN project by Howie Stephens.

Additional features developed for this version include:
- Gadget placement planner
- Gadget and plot autosaving
- Combined download and upload system
- Completion checklists

**Original projects:**
- [Original Slime Rancher Planner](https://github.com/baatochan/SlimeRancherPlanner)
- [Slime Rancher Planner REBORN](https://github.com/deathbypain/SlimeRancherPlanner-REBORN)
